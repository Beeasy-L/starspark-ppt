V2.6 — 先告诉它你讲给谁听
2026-10-26

V2.0 — 每个方向都有自己的骨架了
2026-10-26
  • 不再所有方向套同一个结构：六个方向各有自己的页序骨架，而且每一页都写明了「这一页必须写什么」——不是只给一个页名。
  • 例：职场报告 → 结论页（一句话总体达成率 + 3~5 个头条指标的目标/实际/达成率）→ 核心指标 vs 目标（只有实际没有目标算缺陷）→ 收入结构 → 差异归因（拆出来的原因之和必须等于总缺口） → 项目状态（状态灯 + 证据 + 纠偏动作，含责任人和日期）→ 成本效率（每个数字带单位、期间、口径）→ 下期行动（责任人/时点/量化影响）→ 需决策事项（写明延迟的后果）。
  • 例：商业计划 → 命题封面 → 痛点（让人不安）→ 方案（给人希望）→ 证据（建立信任）→ 商业模式 → 里程碑 → 结果 → 诉求。
  • 骨架来自专业设计规范，每条都注明了出处；网页版和本地服务用的是同一份数据。
  • 另外几条硬规矩：不许以「谢谢」页收尾；只有数字没有「所以呢」算缺陷；同一份里不许连续两页用均分版式。
V1.9 — 图表也能导出，自检不再喊狼来了

  • 渲染兜底：每页渲染前先校验版式契约——缺分隔符、条数不对就自动换一种排得下的版式，宁可变样子也不塌页。
  • 修复：两栏版式的约定和实现互相矛盾（提示词说第 1、2 条是小标题，渲染器却拿第 1 条和中间那条），导致整页结构错乱。
  • 修复：页数不再超生，设几页就出几页。
