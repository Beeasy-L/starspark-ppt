V1.3 — 先说清楚再动手
2026-10-25
  • 新增「先帮我优化提示词」：点一下，AI 会把你的原始素材整理成一份更完善的提示词（补上读者、页数、主线、语气），你可以直接改；确认后才开始生成 PPT，不满意就重来。
  • 新增背景音乐：可在配置区开关与调音量；生成期间自动把音乐压低一档，出稿后平滑恢复。音频只在真正播放时才下载，不影响首屏。
  • 修复一个严重缺陷：主按钮「✦ 生成 PPT」此前没有绑定点击事件——点了完全没反应。现已修好，并改用「真点按钮」的方式重新验证通过。
  • 修复一个「第一次用」就会撞上的缺陷：填了内容但没填 Key 就点生成，按钮会永久卡在「生成中…」、背景音乐一直压在 40% 不恢复。现已把校验提前、清理收进 try/finally，无论中途从哪退出，收尾一定会跑。
  • 修复：流式接口在等「流结束」而不是等「完成信号」，导致部分浏览器下优化会一直转圈。
V1.2 — 可以不用服务器了
2026-10-24
  • 纯前端网页版：同一份页面会自动判断环境——有后端就走后端，没有就在浏览器里直接请求接口。因此它现在是一个可以丢到 GitHub Pages / Netlify 的单文件，不再必须开服务器。
  • PDF 支持（自己写的解析器）：不引任何第三方库，直接解 FlateDecode / ASCII85 压缩流与 ToUnicode 字表，中文能正常还原。已用四份真实中文 PDF 验证（实验报告 / 选课通知 / 数学习题 / 规章制度）。顺手修掉了旧后端「把 PDF 字节当文本读」的假解析。
  • 提示更清楚：扫描件（图片型 PDF）提取不到文字时会明确告知，不会静默失败。
  • Key 保留方式改正：以前填过的 Key 会被浏览器长期记住、下次打开自动填回。现在改为只在当前标签页内有效，关闭页面即清除——公用电脑上不会把上一个人的 Key 留给下一个人。
  • 「如何获取 API Key」四步指南：直接内置在页面上，用户不用去别处找；并说明 Key 只在本机、不上传。
V1.1 — 排版内核重做
2026-10-24
  • 版式 5 → 12 种：新增大数字、时间轴、流程步骤、左右对照、金句页、无竖线表格、交错排布；「卡片」改成细线网格，去掉千篇一律的圆角盒子。
  • 每页多一句「收束句」：页面底部一行细线加一句「所以呢」，讲清这页的结论，不再只是罗列；封面与封底也支持。
  • 标题改成结论：页标题不再是「第二部：某某」这类栏目名，而是一句判断；只读一遍标题就能讲完整个故事。
  • 排版跟随舞台等比缩放：字号与留白改用容器单位，窗口拉大缩小都不会偏大溢出、或偏小显得空。
  • 溢出自动降档：每页渲染后自动量一次，内容超出就按 5% 一档收字号、最多六档，避免文字被裁掉或压边。
  • 版式渲染自检：启动时逐个校验 12 种版式是否真的画得出来，缺一个就当场提示，杜绝「AI 说要用、前端画不出」的静默降级。
  • 生成纪律写进提示词：相邻两页不得同版式、同一版式全篇最多 2 次、每页必须给收束句、禁用「闭环 / 赋能 / 解构」这类 AI 腔。
  • 导出 .pptx 补全：12 种版式各自对应真实排版，收束句一并带出，不再清一色要点列表。
  • 修复：导出的独立 HTML 打不开（切页用的 id 缺失）、中文偶发乱码（跨数据包被劈开的汉字）、卡片序号超过 9 张显示成 010、pptx 脚本因变量自引用一运行就报错。
V1.0 — 首发
2026-10-24
  • 星火PPT 上线：星火三部曲第三部正式诞生——把长文案化为一份逐页可编辑、可放映、可导出的演示文稿，与「星火续火花」「星火专注 Pro」共成燎原之势。
  • API Key 由你自填：模型、接口、Key 全在页面左侧自行配置，选好模型、粘贴自己的 Key 即可生成；Key 只留在当前标签页、关闭即清除，不写磁盘、不进日志。
  • 界面复刻星火专注 Pro 气质：居中鎏金衬线大标题、诗句「星星之火，可以燎原」、深邃夜空蓝 + 玻璃卡片 + 金色描边。
  • 流式逐页生成：6 套模板 × 6 大方向，AI 把内容现场拆成封面 / 要点 / 双列 / 卡片 / 封底，边生成边见效果。
  • 两种导出：独立 HTML（自带放映器）或 python-pptx 脚本一键成真 .pptx。
  • 本地历史：每次生成的 deck 自动保存（最多 30 条），随时重开续改。
