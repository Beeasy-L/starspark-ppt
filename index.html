V1.8 — 导出里也有装饰了
2026-10-26
  • 导出的 .pptx 现在带装饰：网页端 12 套模板各有一个视觉母题，之前导出的是纯版面。现在导出时按同一套母题画图形——图纸网格、角标、数据条、圆环、星点等，和你在网页里看到的一致。
  • 装饰画在内容之下，只用低透明度，不压字；除网格纹理外，其余母题一律只落在页面四周的空白带。

V1.7 — 开始画图了
2026-10-25
  • 新增三种数据图：横向条形（标签 + 条 + 数值）、进度条组（多列纵向对比）、占比环（环 + 中心大字）。全部用内联 SVG 现场绘制，跟随模板配色。
  • 比例是准的：条形长度、柱高、环弧都按数值占最大值的比例算。实测输入 80/40/20 得到 100%/50%/25%；占比 75% 的环弧长 254.5（整圈 339.3）。
  • 什么时候会自动用：只有内容里真的出现了可比较的数字时，AI 才会选图表版式——没有数字就不画，不硬凑。
  • 顺手：环图在小舞台上会溢出，已加尺寸约束；条形/进度/环三种在窄舞台实测均不溢出。
V1.6 — 补上图形、按规范重排、导出不再出界
2026-10-25
  • 模板终于有「图样」了：12 套模板各配一个视觉母题——星轨、月相、山峦、印章、雾带、波浪、图纸网格、斜切色带、纸感、数据条、圆环、方格；另加角落角标、标题标记、页脚装饰与一套图标库。装饰一律只落在空白处，不压文字。

  • 两套模板换了气质：「紫雾星海」的紫蓝渐变被专业规范明文禁止，改成「琥珀长夜」；「沧海深蓝」改成浅色的「沧海晨光」，缓解深底过多。
  • 导出 .pptx 不再出界：12 页逐形状断言，越界 0 个、图文重叠 0 处；并支持把 AI 配图一起嵌进 pptx。
  • 配图（AI 生图）：填任一家 OpenAI 兼容的生图接口（智谱 / 通义万相 / 硅基流动 / OpenAI），勾选后自动为封面配图，内容页也能单独配。
V1.5 — 导出真的是 .pptx 了
2026-10-25
  • 导出 .pptx 不再是给一个 .py 脚本：以前点导出会下载一段 Python 代码，用户还得自己装环境去跑——那不是导出。现在点一下，直接拿到一个 PowerPoint 能打开的 .pptx 文件。
  • 文件是自己生成的，没引任何库：ZIP 打包和 OOXML 全部手写，纯浏览器内完成，所以纯网页版也能用，不用服务器。
  • 12 种版式在 pptx 里各自独立排版：封面居中大标题、大数字页、时间轴、流程、左右对照、金句、表格、交错——不是清一色要点列表。每页的收束句作为备注一起带走。
  • 配色跟着你选的模板走：导出时读取当前模板的实际颜色。
  • 体积：8 页约 108 KB，不用压缩库。
V1.4 — 把「生成质量」往上抬一档
2026-10-25
  • 模板 6 → 12 套，这次是真模板不是换色：每套在底色气质、标题字体、字重字距、列表标记、装饰形态五个维度上都不一样；新增 3 套浅色（米白学术 / 暖砂手记等），不再全是深底。
  • 星月诗笺接入：三部曲共用的 30 句诗，封面给整句带出处、内容页页脚给半句（同一份里不重复）、封底给整句且不与封面撞句。换一份生成就换一批诗。
  • 提示词升级：加「槽位语法」硬规则 + 一份 6 页完整范例，让模型知道每条要点该怎么写，版式不再靠猜。
  • 渲染兜底：每页渲染前先校验版式契约——缺分隔符、条数不对就自动换一种排得下的版式，宁可变样子也不塌页。
  • 修复：两栏版式的约定和实现互相矛盾（提示词说第 1、2 条是小标题，渲染器却拿第 1 条和中间那条），导致整页结构错乱。
  • 修复：页数不再超生，设几页就出几页。

V1.2 — 可以不用服务器了
2026-10-24
  • 纯前端网页版：同一份页面会自动判断环境——有后端就走后端，没有就在浏览器里直接请求接口。因此它现在是一个可以丢到 GitHub Pages / Netlify 的单文件，不再必须开服务器。
  • PDF 支持（自己写的解析器）：不引任何第三方库，直接解 FlateDecode / ASCII85 压缩流与 ToUnicode 字表，中文能正常还原。已用四份真实中文 PDF 验证（实验报告 / 选课通知 / 数学习题 / 规章制度）。顺手修掉了旧后端「把 PDF 字节当文本读」的假解析。
  • 提示更清楚：扫描件（图片型 PDF）提取不到文字时会明确告知，不会静默失败。
  • Key 保留方式改正：以前填过的 Key 会被浏览器长期记住、下次打开自动填回。现在改为只在当前标签页内有效，关闭页面即清除——公用电脑上不会把上一个人的 Key 留给下一个人。
  • 「如何获取 API Key」四步指南：直接内置在页面上，用户不用去别处找；并说明 Key 只在本机、不上传。
V1.1 — 排版内核重做
2026-10-24
  • 版式 5 → 12 种：新增大数字、时间轴、流程步骤、左右对照、金句页、无竖线表格、交错排布；「卡片」改成细线网格，去掉千篇一律的圆角盒子。
  • 每页多一句「收束句」：页面底部一行细线加一句「所以呢」，讲清这页的结论，不再只是罗列；封面与封底也支持。
  • 标题改成结论：页标题不再是「第二部：某某」这类栏目名，而是一句判断；只读一遍标题就能讲完整个故事。
  • 排版跟随舞台等比缩放：字号与留白改用容器单位，窗口拉大缩小都不会偏大溢出、或偏小显得空。
  • 溢出自动降档：每页渲染后自动量一次，内容超出就按 5% 一档收字号、最多六档，避免文字被裁掉或压边。
  • 版式渲染自检：启动时逐个校验 12 种版式是否真的画得出来，缺一个就当场提示，杜绝「AI 说要用、前端画不出」的静默降级。
  • 生成纪律写进提示词：相邻两页不得同版式、同一版式全篇最多 2 次、每页必须给收束句、禁用「闭环 / 赋能 / 解构」这类 AI 腔。
  • 导出 .pptx 补全：12 种版式各自对应真实排版，收束句一并带出，不再清一色要点列表。
  • 修复：导出的独立 HTML 打不开（切页用的 id 缺失）、中文偶发乱码（跨数据包被劈开的汉字）、卡片序号超过 9 张显示成 010、pptx 脚本因变量自引用一运行就报错。
